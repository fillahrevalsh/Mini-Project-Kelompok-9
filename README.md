# Mini-Project-Kelompok-9
# 💰 Program Tabungan Keuangan

## 📘 Deskripsi
Program *Tabungan Keuangan* adalah mini project berbasis C yang bertujuan membantu pengguna dalam *mengelola keuangan harian*, seperti mencatat pemasukan, pengeluaran, serta menghitung saldo akhir.  
Program ini dibuat untuk memenuhi tugas *Mini Project - Pengenalan Pemrograman*, dengan ketentuan penerapan:
- Function  
- Perulangan  
- Percabangan  
- Array  

Program ini bersifat *interaktif di terminal (console)* dan bermanfaat untuk kehidupan sehari-hari dalam mengatur keuangan pribadi secara sederhana.

---

## 🧩 Fitur Utama (Menu Program)
1. *Tambah Pemasukan*
   - Pengguna dapat mencatat nominal pemasukan beserta keterangan (contoh: gaji, hadiah, dll).

2. *Tambah Pengeluaran*
   - Catat pengeluaran harian (contoh: makan, transportasi, hiburan, dll).

3. *Lihat Riwayat Transaksi*
   - Menampilkan seluruh daftar pemasukan dan pengeluaran yang sudah dimasukkan.

4. *Hitung Saldo Akhir*
   - Menampilkan total saldo berdasarkan selisih antara pemasukan dan pengeluaran.

5. *Statistik Keuangan*
   - Menampilkan ringkasan sederhana seperti:
     - Total pemasukan
     - Total pengeluaran
     - Pengeluaran terbesar & terkecil

## 🧠 Konsep dan Logika
Program ini menggunakan:
- *Array* → Menyimpan data pemasukan dan pengeluaran  
- *Function* → Setiap menu dibuat dalam function terpisah  
- *Perulangan (loop)* → Untuk navigasi menu dan menampilkan daftar transaksi  
- *Percabangan (if / else)* → Untuk menentukan logika perhitungan dan validasi input
